# Viscose Design

Front-end storefront concept for **Viscose Design**, focused on occasion and everyday mukhawars.

## Current scope

- Arabic / English interface
- Luxury visual direction based on the brand's plum, gold, ivory, beige and brown palette
- Occasion collection: A1, A2, B1
- Everyday collection: B2
- Sizes: 50, 52, 54, 56, 57 + custom size
- Customer-entered preferred color
- Order bag that sends the complete order to WhatsApp
- Instagram link
- Responsive layout for desktop and mobile
- Temporary price and image treatments until final product assets arrive

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The site is intentionally front-end only. Orders are passed to WhatsApp rather than stored in a backend database.
